# Supported networks

GitWallet derives addresses for 14 blockchains from a single BIP39 seed phrase.

| Network | Assets |
|---------|--------|
| Bitcoin | BTC |
| Ethereum | ETH, ERC-20 tokens, NFTs |
| BNB Chain | BNB, BEP-20 tokens |
| Solana | SOL, SPL tokens, NFTs |
| Tron | TRX, TRC-20 tokens |
| Polygon | MATIC, tokens, NFTs |
| Arbitrum | ETH, tokens |
| Optimism | ETH, tokens |
| Base | ETH, tokens |
| Avalanche | AVAX, tokens |
| Litecoin | LTC |
| Dogecoin | DOGE |
| XRP Ledger | XRP |
| Cosmos | ATOM |

Thousands of tokens are supported across the EVM and non-EVM chains above. Futures trading is available via Hyperliquid.
