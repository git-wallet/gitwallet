# Contributing

Thanks for your interest in GitWallet! This repository hosts the public website and documentation.

## Ways to help

- **Report a bug or typo** on the website or docs — open an [issue](../../issues).
- **Suggest an improvement** to the docs or landing page via a pull request.
- **Translations** — the app ships in 16 languages; doc translations are welcome too.

## Website

The site in `website/` is plain static HTML/CSS/JS — no build step.

```bash
# serve locally with any static server, e.g.:
cd website
python -m http.server 8080
# open http://localhost:8080
```

## Security

Please do **not** report security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
